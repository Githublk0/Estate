# EstateFlow attribution and license review

## Krayin CRM
EstateFlow uses Krayin CRM as the intended backend foundation. The supplied Krayin 2.2 project includes its own `LICENSE` file and package-level code under `packages/Webkul`. Preserve that license and upstream attribution in any distributed derivative.

Before commercial distribution, have counsel review the exact Krayin license text and obligations for the selected release.

## Twenty CRM
Twenty is not incorporated into EstateFlow. It remains an evaluated alternative/reference only. Do not copy Twenty code or assets into this repository without a separate compatibility and attribution review.

## EstateFlow additions
New EstateFlow package code is maintained separately under `packages/Webkul/EstateFlow`. Keep its own copyright/attribution headers and dependency notices current as dependencies are added.
